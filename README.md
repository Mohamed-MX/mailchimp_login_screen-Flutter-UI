## 📱 About

This project demonstrates a responsive and visually appealing implementation of a modern login screen using Flutter. It focuses on:
- Clean, structured, and maintainable UI code.
- Cross-platform support (Android, iOS, Web).
- Proper use of Flutter widgets, typography, and styling to match modern app aesthetics.

## 🚀 Getting Started

To run this project locally, ensure you have [Flutter installed](https://docs.flutter.dev/get-started/install) on your machine.

1. **Clone the repository** (if hosted on GitHub):
   ```bash
   git clone <your-repo-url>
   ```

2. **Navigate to the project directory**:
   ```bash
   cd mailchimp_login_screen_Flutter_UI
   ```

3. **Install dependencies**:
   ```bash
   flutter pub get
   ```

4. **Run the app**:
   ```bash
   flutter run
   ```
